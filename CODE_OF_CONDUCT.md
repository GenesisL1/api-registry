# Code of conduct

This is public infrastructure. Everyone here is trying to make it work.

**Expected:** engage with the strongest version of what someone said, take
disagreement about design as disagreement about design, accept that "no" is a
complete answer to a proposal, and assume the person on the other side has context
you do not.

**Not accepted:** harassment, personal attacks, sustained disruption, publishing
private information, or using measurement disputes to pressure an operator rather
than to correct a record.

**On disputes about the register itself:** the contract already provides the
mechanism. If you believe an endpoint's record is wrong and you operate it, record
your account on-chain with `contestEndpoint`. That is public, permanent and
attached to the endpoint, which makes it more useful than an argument in an issue
thread.

**Enforcement.** Report to the maintainers through the contact on
[genesisl1.com](https://genesisl1.com), or via a private security advisory if the
matter is sensitive. Maintainers may remove comments, close threads, or block
accounts. Serious or repeated cases result in a permanent ban.

Maintainers are held to this more strictly than anyone else, not less.

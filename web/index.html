What is measured

Real protocol calls

Checkers make actual calls — a chain ID, a block height, a WebSocket round trip, an HTTP/2 handshake — not a bare TCP connect. A node that answers but stopped importing blocks is recorded as failing.

What reaches the chain

Only adverse days

Minute-level history stays in each checker's local database. The chain stores registry records and a compact daily attestation, written only when an endpoint misses its target or recovers from a flag.

Why you can trust it

Quorum and signatures

No single checker can flag an endpoint; a quorum of independently authorized checkers is required, and clearing a flag needs the same. Every telemetry feed this page reads is signature-checked against the on-chain checker roster before a number is shown.
